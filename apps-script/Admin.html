วิธีใช้

  • ★ คำถามที่เตรียมไว้ แสดงบนสุดของ Session เสมอ ใช้ในกรณีผู้เข้าร่วมไม่มีคำถาม
  • คำถามจากผู้เข้าร่วมมี เลขลำดับ 1, 2, 3 … ตามลำดับที่ส่งเข้ามาใน Session นั้น (ใหม่สุดอยู่บน)
  • Speaker เปิด Session เพื่ออ่านคำถาม (ดูอย่างเดียว)
  • Officer กด “✓ ตอบแล้ว” เมื่อ Speaker ตอบคำถามนั้นแล้ว / ติดดาว / เขียนโน้ต / ย้ายคำถามที่เข้าผิด Session
  • คำถามเข้า Session ตามเวลาอัตโนมัติ ถ้ากำหนดการเลื่อน Officer เลือก Session ที่กำลังรับคำถามด้านบนเองได้
